DeepSeek 悬浮球 · 效果一览

Chrome 扩展（Manifest V3）。一个能拖动、带惯性的鲸鱼小球，双击开对话面板，读网页、看图、拖文件进来直接问。

① 加载扩展打开 chrome://extensions，开启开发者模式，点「加载已解压的扩展程序」，选 floating-ball 这个文件夹（就是你 clone / 解压出来的那个）
② 配 API Key面板右上角 ⚙（或扩展详情页的「扩展选项」）打开设置页，把 key 粘进去点保存。代码里不写 key。
③ 刷新在扩展页点本扩展的刷新按钮，再到任意网页按 F5。球会出现在窗口右侧、屏幕高度约 60% 的位置。

文件角色

文件作用
manifest.json清单：名称、图标、权限、脚本注入规则、设置页入口
config.js你要动的文件：模型列表、思考档位、界面人设（API Key 不在这儿）
options.html + options.js设置页：API Key 在这儿配，存在浏览器里，代码里不留
panel.js对话面板：界面、历史记录、流式请求、读网页、附件、取 Key
content.js悬浮球本体：拖动、惯性、吸附、双击开面板、接收拖拽
sidepanel.html + sidepanel.js侧边栏入口：点工具栏图标，右侧栏里跑同一个面板
background.js后台脚本，三件事：截图、工具栏图标开侧栏、首装提醒配 Key
icons/工具栏图标 16 / 48 / 128
README.md完整说明文档（安装、参数、实现细节）
docs/本页 + 截图 + 三个自检页 + 图标源文件，不影响运行，可整包删除

只有上面 9 个文件加 icons/ 是运行必需的。要打包上架，`README.md` 和 `docs/` 可以先排除。
