字幕实时翻译

抓取网页视频自带的字幕轨，用 DeepSeek 预取翻译后叠加在画面上

API Key 必填

粘贴 DeepSeek 平台的 API Key。只写入本机浏览器的 chrome.storage.local，不上传到任何第三方，也不会出现在扩展代码里。

接口

翻译请求固定关闭 thinking 模式——字幕翻译不需要推理过程，开着会先输出一段思考，延迟和费用都翻倍。

翻译行为

预取提前量越大越不容易出现「字幕慢半拍」，但请求发得越早。45 秒是个稳的起点。

怎么用

    
    
      
  1. 把 DeepSeek 的 API Key 粘到上面第一格，点「测试连接」确认通了，再点「保存设置」。
    2. 
      
  2. 打开带英文字幕的视频页，先在播放器里把字幕（CC）打开——扩展抓的是播放器自己下载的那份字幕文件，不开就不会有请求。
    3. 
      
  3. 字幕一加载，中文就会叠在画面上。右上角扩展图标能看到当前用的是哪一级字幕源。
    4. 
      
  4. 如果某个站点没有反应，点扩展图标看「字幕来源」；显示「未检测到视频」或来源一直为空，就是这一站的字幕既不是文件也不是原生轨。
